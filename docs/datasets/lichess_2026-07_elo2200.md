## Known caveats

- Ingestion filters on Elo and time control only, not game completion — the 1 unfinished games above are still in the file, and contribute 0 training positions when consumed via `ChessPositionDataset`, which skips them.
- The position count is an estimate, not exact: 5,000 finished games were fully replayed via python-chess to measure average game length, then extrapolated to all 199,999 finished games. An exact count would require replaying all of them, which is the same per-game cost that made the original ingestion slow (~15 minutes for this many games) — not worth paying just for documentation.
